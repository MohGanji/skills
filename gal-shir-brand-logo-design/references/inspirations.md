# Inspirations — Gal Shir's work, reverse-engineered

Study how Gal Shir turns **brand story → values → audience → strategy** into **one smart,
minimal symbol**, using his real marks as worked examples. Each example in
`inspirations/<brand>/` is built from a **blind, multi-agent reverse-engineering** of an
actual logo he designed, plus the real downloaded assets.

## How each example was built (the blind method)

For every mark, **three independent investigators worked without seeing each other's
findings**:

1. **Brand truth** — read only the brand's own website: story, audience, identity,
   values, strategy, personality.
2. **What Gal said** — found only the designer's public commentary about the mark.
3. **The mark, read blind** — deconstructed the actual logo **SVG with no idea what the
   brand is** — a pure "what does this shape alone say?" read.

Then a **consolidation** tests the hypothesis: *if Gal did his job, the blind reader
should recover the brand truth from the mark alone.* Where all three align, we've
reverse-engineered his thinking; where they diverge, that's recorded honestly (an
**alignment score** of strong/partial/weak per mark).

## What each folder contains

**Everything here is a real, publicly-sourced reference — no reconstructions or generated
art.**

```
inspirations/<brand>/
  analysis.md          # the 3 blind investigations (kept distinct) + consolidation
  original.svg / .png  # the real published logo, downloaded (a stable copy)
  images/              # Gal Shir's own project showcase (galshir.com/#<brand>):
                       #   the mark on merch, devices, print, in real environments
```
